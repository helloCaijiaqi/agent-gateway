通路 / 回路编排

—

步骤两级解析：内置 protocol → 装饰器/过滤器角色（单值 role）的登记工具名（服务 id 直接当步骤已不合法）。每个步骤可展开「规则」配置注入方式：once（仅会话首轮，进缓存前缀省 token）· 前缀/后缀 · 正则替换（{extra} 占位）· 自定义拼接函数（(message, extra) => string，强制 return）· 本地静态文本（零服务调用）。通路作用于入站 prompt；回路（P5 已生效）作用于发送动作的外发文本——filter 产出空串拦截投递、非空替换外发内容，GATEWAY_PIPELINE=off 时双向透传。空编排 = 透传。
